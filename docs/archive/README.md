`docs/ops/`, `docs/specs/`, `docs/architecture/`, den gelisteten Dateien unter
`docs/concepts/` und im Code (`CLAUDE.md`, `DESIGN.md`).

Entscheidung nur noch als Historie dokumentieren oder eine UI-Skizze ablösen,
die längst im Produkt steht.
